Introducing

Visualize Your GitHub Projects with Dynamic SVGs

An elegant API that queries GitHub repositories and generates beautiful SVG visualizations that you can embed anywhere — perfect for your README profiles.

View on GitHub
repository-visualization

Features

  • Integration with GitHub README.md Query a specific project repository and generate a custom SVG/image that can be added to your README.
  • Integration with HTML pages Retrieve all, selected, or pinned repositories in a JSON format containing beautifully decorated SVG cards that can be easily added to your webpage.
  • Themes and Customization Choose from different themes and styles to personalize your SVG cards.
Usage

How to Use GitSVG API

Follow these simple steps to integrate dynamic SVGs into your projects.

1. Make a GET request to our API

Simply call our endpoint with your GitHub username and repository name.

API Request Example
GET https://svg-projects-card.onrender.com/api/bulushamnu/repos/Demi-Tasks?theme=dark&imageurl=https://bulusdev.vercel.app/Asserts/images/demi_tasks_cover.png

2. Receive SVG Response

The API returns an SVG/IMAGE representation of your project with relevant metadata.

Response Example
<svg width="400" height="200" xmlns="http://www.w3.org/2000/svg"><!-- SVG content --></svg>

3. Embed in Your README

Add the image to your GitHub profile or repository README.

Markdown Example
![Project Visualization](https://svg-projects-card.onrender.com/api/bulushamnu/repos/Demi-Tasks?theme=dark&imageurl=https://bulusdev.vercel.app/Asserts/images/demi_tasks_cover.png)

Svg card with image

Custom Parameters

theme= "dark" | "light" | "warm" | "cool"
Username= Your github username
pinned= "true" | "false" (When requesting multiple repo)
imageurl= add imageurl as param for project cover img.
