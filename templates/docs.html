Getting All Repositories

You can query the endpoint below to retrieve multiple project repositories with custom SVG cards.

To get only pinned repositories, use the pinned=True parameter. To get all public repositories, use pinned=False.

you can also choose one of four available themes: dark | light | warm | cool.

Request Example
GET https://svg-projects-card.onrender.com/api/bulushamnu/repos?theme=dark&pinned=True
Reponse Example

{
    "data" : [
    "list of raw svg images"
    ]
}

Adding Cover Images

You cannot use the imageurl parameter in a GET request because it does not specify which repository the image should be added to.

To add a cover image, use the POST method on the same endpoint without query parameters.

Endpoint
POST https://svg-projects-card.onrender.com/api/bulushamnu/repos

Request Body (JSON Format)

Send a JSON body containing a list of repository names, themes, and optional imageurl values (ensure it is a valid image link).

Json example
    
{
    repos : [
    {
        "name" : 'animeq-game',
        "theme" : "cool",
        "imageurl" : "https://bulusdev.vercel.app/Asserts/images/animequiz.png"

    },

    {
        "name" : 'Portfolio-V1',
        "theme" : "light",
        "imageurl" : "https://bulusdev.vercel.app/Asserts/images/bulus_dev_cover.png"

    },
    {
        "name" : 'Demi-Tasks',
        "theme" : "warm",
        "imageurl" : "https://bulusdev.vercel.app/Asserts/images/demi_tasks_cover.png"

    },
    ]
}

Getting a Single Repository

To retrieve a custom SVG card for a single repository, use the following format

  • The theme parameter accepts one of four options: dark | light | warm | cool.
  • The imageurl parameter (optional) can be added to include a cover image (ensure it's a valid URL)
  • The response is an SVG image that can be embedded directly using the <img> tag.
Request Example
<img src="/api/bulushamnu/repos/Demi-Tasks?theme=dark" alt="Demi-Tasks" >

GitHub Integration

This API is designed to enhance your GitHub README.md file with stylish SVG visualizations of your projects.

Embedding a Single Repository in a README

Request Example
![Project Visualization](https://svg-projects-card.onrender.com/api/bulushamnu/repos/Demi-Tasks?theme=dark)

Or

Request Example
<img src="https://svg-projects-card.onrender.com/api/bulushamnu/repos/Demi-Tasks?theme=dark" alt="Demi-Tasks">

Displaying Multiple Projects in a README

GitHub does not allow direct scripting in README files, but you can bypass this limitation using GitHub Actions.

How it Works:

  • Create a GitHub workflow that triggers manually.
  • The workflow queries the API using curl.
  • The response is written to your README file dynamically.

I have a sample workflow YAML file on this site GitHub repo Here that you can download and customize based on your needs.
